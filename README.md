# 星穹铁道 · 回合数/行动值监控提醒 v2

监控游戏左侧行动序列列中的倒计时条（沙漏 + 回合数 + 行动值），当 **回合数 == 0 且 行动值 < 30** 时弹出醒目提醒窗口并响铃。

v3 主要特性：
- **窗口直捕**：PrintWindow 直接捕获游戏窗口（与 OBS 同机制），游戏窗口在屏幕上可见即可——不需要游戏在前台/聚焦，被部分遮挡也能读
- **动态定位**：倒计时条随角色行动在列内上下浮动，程序每帧自动重新定位
- **HDR 适配**：系统自动做 HDR→SDR 转换，画面不过曝；另有 gamma 参数可微调
- **自动提权**：start.bat 启动时自动申请管理员权限（与游戏同权限，捕获更可靠）
- **识别日志**：每次识别成功自动记录到 logs/history_日期.csv（时间/回合数/行动值/是否提醒），数字变化或触发提醒时保存识别画面到 logs/frames/（自动保留最近 500 张）
- **结果三重校验**：识别值经「数值范围（回合≤9、行动值≤200）+ 时序单调（同一场战斗内只递减）+ 两帧确认（突增疑似新战斗重置，连续两帧高位递减才接受）」过滤，离谱结果直接丢弃，不进日志不存档

## 使用步骤

1. 启动游戏，进入战斗界面（倒计时条可见的界面）。
2. 双击 `start.bat` 打开监控程序（若旧版监控窗口还开着，先关掉它）。
3. 确认捕获方式为「**窗口捕获(推荐,后台可用)**」。
4. 确保游戏窗口在屏幕上**可见**（窗口化即可，不必在前台；不要最小化或移出屏幕，否则游戏不渲染画面，任何工具都捕获不到）。
5. 点击 **「选择监测区域」**——程序会抓取游戏窗口画面，在弹出窗口中用鼠标**框选倒计时条所在的整列**：
   - 倒计时条（沙漏+回合数+行动值）在左侧行动序列列中会上下浮动，所以框选时要**上下留足浮动空间**，框满整列高度；
   - 水平方向框住沙漏到行动值条即可。
6. 松手后自动测试识别，日志区应显示「回合数=X 行动值=Y」。
7. 点 **「开始监测」** 即可。游戏窗口在屏幕上（不必前台）即可持续监测。

## 参数说明

- **回合数等于 / 行动值小于**：触发条件（默认 0 / 30）
- **间隔(毫秒)**：识别频率（默认 500）
- **gamma**：画面亮度校正。HDR 下画面过曝发白时调低（如 0.7），过暗调高
- **捕获方式**：窗口捕获（推荐，后台可用）/ 屏幕区域（游戏必须可见，被遮挡会读到别的窗口）
- **仅游戏窗口在前台时监测**：仅屏幕模式需要，默认关闭（窗口模式无需）

## 常见问题

- **「未找到游戏窗口」**：游戏没启动，或窗口标题关键字（config 中 `window_keyword`，默认"崩坏"）对不上
- **「未定位到倒计时条」**：区域框得不对（应框整列且包含倒计时条活动范围），或当前不在战斗界面
- **窗口捕获黑屏/失败**：部分显卡驱动或全屏独占模式下 WGC 受限，可切「屏幕区域」模式
- **游戏窗口改了大小**：监测区域是相对窗口的坐标，改窗口大小后需重新框选
- **误报/漏报**：调节阈值、间隔、gamma；确保区域只包含倒计时列
- **自检模式**：`venv\Scripts\python.exe starrail_monitor.py --selftest 截图.png`（定位图中红色矩形框区域并识别）

## 数值校验说明

- 回合数合理范围 0-9、行动值 0-200（config.json 中 `max_turn` / `max_action` 可调）
- 行动值同一场战斗内只允许递减；突增视为疑似新战斗开始，需下一帧保持高位递减才确认（防止误读造成假提醒）
- 被丢弃的结果不会写入 CSV、不保存画面、不触发提醒，界面状态栏会显示丢弃原因

## 已知限制

- 回合数字按游戏当前渲染的**黄色**识别；若版本更新后颜色变化，兜底路径仍可识别但准确性下降
- 首次使用务必先「测试识别」确认读数正确，再开始监测
